> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace developer-facing boolean strings and default-styled controls with polished visual indicators, typographic hierarchy, and status-aware UI across three XAML files.

**Architecture:** All changes are purely cosmetic XAML edits — no new C# types, converters, or view-model properties. Each task is self-contained and buildable independently. There are no automated tests to write; each task ends with a build verification to catch XAML parse errors.

## Task 7: Video thumbnail extraction in queue items

**Files:**
- Modify: `src/VideoTriage.App/ViewModels/FileItemViewModel.cs`
- Modify: `src/VideoTriage.App/ViewModels/MainViewModel.cs`
- Modify: `src/VideoTriage.App/Views/MainWindow.xaml`

### Context

The queue item template in `MainWindow.xaml` renders a static grey `Border` (96×56 px) as a
placeholder — no thumbnail is loaded. `FileItemViewModel` has no image property. `MainViewModel`
scans files using `ffprobe`; `ffmpeg` is already a verified prerequisite on PATH.

The approach: after each file is probed and added to the queue, fire-and-forget an async
`ExtractThumbnailAsync` that calls `ffmpeg` to extract a single frame to a temp PNG, loads it
into a frozen `BitmapImage` via `StreamSource` (to avoid file-URI formatting issues), dispatches
the result onto the UI thread, then deletes the temp file. `BitmapCacheOption.OnLoad` ensures the
bytes are fully in memory before the file is deleted. `Freeze()` makes the bitmap thread-safe for
cross-thread dispatch. Extraction is best-effort — failures leave `Thumbnail` null and the grey
background shows through.

`DecodePixelWidth = 96` limits decoding to the display size, avoiding loading a full 4K frame
into memory for a 96 px thumbnail.

In `src/VideoTriage.App/ViewModels/FileItemViewModel.cs`, add to the using block at the top:

- [ ] **Step 2: Add thumbnail extraction to MainViewModel**

In `src/VideoTriage.App/ViewModels/MainViewModel.cs`, add to the using block at the top:

```csharp

using System.Windows.Media.Imaging;
```

In `ChooseFolderAsync`, find the block inside the `IProgress<ProbeResult>` callback
(approximately line 153):

```csharp

```

Replace with:

```csharp

row.ApplyProbe(result);
Items.Add(row);

```

Add the following private method to `MainViewModel` before the `InlineProgress` nested class
(approximately line 287):

```csharp
private async Task ExtractThumbnailAsync(FileItemViewModel row, string filePath)
{
    var temp = Path.Combine(Path.GetTempPath(), $"vt_thumb_{Guid.NewGuid():N}.png");
    try
    {
        using var proc = new Process();
        proc.StartInfo = new ProcessStartInfo
        {
            FileName = "ffmpeg",
            Arguments = $"-ss 1 -i \"{filePath}\" -vframes 1 -q:v 2 -loglevel quiet \"{temp}\" -y",
            CreateNoWindow = true,
            UseShellExecute = false
        };
        proc.Start();
        await proc.WaitForExitAsync();

        if (proc.ExitCode == 0 && File.Exists(temp) && new FileInfo(temp).Length > 0)
        {
            using var stream = new MemoryStream(File.ReadAllBytes(temp));
            var bitmap = new BitmapImage();
            bitmap.BeginInit();
            bitmap.CacheOption = BitmapCacheOption.OnLoad;
            bitmap.StreamSource = stream;
            bitmap.DecodePixelWidth = 96;
            bitmap.EndInit();
            bitmap.Freeze();
            _dispatcher.Post(() => row.Thumbnail = bitmap);
        }
    }
    catch
    {
        // Thumbnail extraction is best-effort; failures leave Thumbnail as null
    }
    finally
    {
        try { File.Delete(temp); } catch { }
    }
}
```

- [ ] **Step 3: Replace the grey placeholder with an Image in the queue item template**

In `src/VideoTriage.App/Views/MainWindow.xaml`, find the grey placeholder Border
(approximately line 210):

```xml
<Border Width="96"
        Height="56"
        CornerRadius="4"
        Background="#247F7F7F" />
```

Replace with:

```xml
<Border Width="96"
        Height="56"
        CornerRadius="4"
        ClipToBounds="True"
        Background="#247F7F7F">
    <Image Source="{Binding Thumbnail, Mode=OneWay}"
           Stretch="UniformToFill" />
</Border>
```

`ClipToBounds="True"` clips the image to the Border's layout bounds. `Mode=OneWay` is required
because `Image.Source` could otherwise attempt a TwoWay binding against the read-only
`Thumbnail` setter. When `Thumbnail` is null the `Image` renders nothing and the grey
`Background` shows through.
